# Ablation study — OurMethod, seed 0, our setup

**Branch:** `ablations` (off main, commit `4464929`).
**Status:** runs in progress; this table is updated as each finishes.
**Setup:** CIFAR-10, Dir(0.1), 20 clients, 200 rounds, 5 local epochs, batch 64, single sudden drift at round 100. OurMethod defaults: EMA α=0.3, warmup=10. Single seed=0 only — see caveat below.

## Variants

Each variant ablates ONE knob in OurMethod; everything else is identical. The diff is two CLI overrides (`--ablation-tau`, `--ablation-all-layers`) applied at `__main__` before any method runs; see commit `4464929`.

| # | Variant | Knob changed |
|---|---|---|
| 0 | **baseline** | none — unmodified OurMethod (τ=1.4, drift-layers L3+L4) |
| 1 | **no-detection** | τ=∞ (no layer ever flags → OurMethod reduces to FedAvg-equivalent through the selective-sync path) |
| 2 | **all-layers** | drift-layers = {L1, L2, L3, L4} instead of {L3, L4} |
| 3 | **tau-low** | τ=1.2 |
| 4 | **tau-high** | τ=1.6 |

## How the metrics are computed

- **Pre-drift acc:** mean global test accuracy over rounds [89, 99] (the 11 rounds immediately before drift).
- **Dip:** Pre-drift acc minus the minimum global test accuracy in rounds [100, 109] (the 10 rounds immediately after drift). Smaller is better.
- **Post-drift stable:** mean global test accuracy over rounds [190, 199] (the last 10 rounds).
- **Δ-pre / Δ-stable:** variant minus baseline (positive means variant beats baseline).

## Single-seed caveat (honest)

This study is single-seed (seed 0) due to time pressure for the morning meeting. The 1-sigma seed variance on these metrics in our prior 3-seed runs was on the order of 0.5–1.5pp. Effect sizes smaller than that should not be interpreted as differences; they are noise. Treat this table as a relative ranking with that uncertainty in mind. Multi-seed replication is the obvious follow-up.

## Headline takeaways (single seed — read with the noise caveat above)

1. **Disabling detection (τ=∞) does not measurably change post-drift stable acc** (−0.08pp vs baseline). Within seed noise — the detection mechanism's contribution to *canonical-test global accuracy* is not visible at n=1. (Earlier multi-seed runs showed the same pattern.)
2. **Lowering τ to 1.2 dramatically reduces the dip** (0.0740 vs baseline 0.1196 = **−4.56pp smaller dip**) while leaving stable basically unchanged. The most differentiated knob in this study. More-sensitive flagging → more clients keep local L3/L4 at drift → softer landing.
3. **Making all 4 layers flaggable adds nothing** (+0.10pp stable). The L3+L4 restriction isn't hurting.
4. **Higher τ (1.6) leaves dip about the same as baseline** and stable marginally up (+0.81pp), but this is well inside seed noise.

The τ knob is the only one in this set that produces a clear functional effect at n=1.

## Reference baseline note

The baseline is the FRESH variant-0 run in Batch 1 on this `ablations` branch — same commit, same code path, only the (zero) ablation flags differ from the other four variants. The prior `runs/2026-05-28-hybrid/seed0/results_OurMethod.csv` is **not** reused, because between that commit (`49e405f`) and this one (`4464929`) the drift-trigger expression changed from `if rnd == DRIFT_ROUND` to `if rnd in DRIFT_SCHEDULE`. The two are mathematically equivalent for single-event drift but bit-for-bit identity on CUDA cannot be proved.
